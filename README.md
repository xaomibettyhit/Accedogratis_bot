# Accedo Gratis Fútbol Bot

Bot de Telegram en español para información de fútbol: partidos, resultados y ligas europeas.

## Funciones
- Partidos de hoy
- Próximos partidos
- Resultados recientes
- Selección de liga favorita
- Notificaciones automáticas cada 6 horas

## Despliegue en Railway
1. Sube este repositorio a GitHub.
2. Crea un proyecto en Railway desde el repositorio.
3. Configura la variable: `TELEGRAM_BOT_TOKEN`
4. Despliega.

## Actualizar datos
Edita `data.py` en GitHub. Railway se redespliega automáticamente.
